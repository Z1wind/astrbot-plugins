# 用法

两种方式并存：

1. **自动**：插件加载后每 5 分钟（`auto_interval_minutes` 可改）查一次 Telegram 指定群，有新消息就把结果渲染成**一张卡片图**推到群；没有新消息时完全静默，不会发「0 条」。
2. **手动**：QQ 群里发 `/tg`（QQ 官方平台需要 @机器人），立刻查一次并回一张同样的卡片图。

卡片内容只有：群名、新增几条、时间段、谁说得多。昵称或 @用户名 含 lgd 时，底部打一枚「LGD的奇妙冒险」标签，**不再写「lgd 发了 N 条」**。

## 自动播报发到哪个群？

- 优先用配置 `notify_umo`（写死目标会话）；
- 留空时，**在哪个群发过一次 `/tg`，就锁定那个群**（插件把该会话记在 `data/notify.json`）。
  所以第一次部署时，去羊村群 `@乐乐 /tg` 一次，之后自动播报就发到那里。

## 指令

| 指令 | 作用 |
|---|---|
| `/tg` | 查一次增量（首次只建立基线，不刷历史），回卡片图 |
| `/tg状态` | 看监看的群、游标、上次检查、自动监听开关、推送目标、连接状态 |

## 配置要点

- `watch_chat`：要监看的群，默认留空，需在配置里填写目标群，也可填 `@用户名` / `t.me 链接` / 群标题。
- `watch_user`：关键词，默认 `lgd`，昵称或用户名包含即命中，忽略大小写。
- `special_text`：命中时卡片上的标签文字，默认 `LGD的奇妙冒险`。
- `auto_watch` / `auto_interval_minutes`：自动监听开关与间隔（默认开、5 分钟）。
- `source_dir`：爬虫工具 dist 目录，默认从这里读 `config.json` 与 `sessions/crawler.session`。
- `proxy`：留空自动读 Windows 系统代理；填 `direct` 强制直连。
- `show_senders`：卡片上是否列发言人（默认列前 3 位 + 人数合计）。

## 实现要点

- 会话文件会**复制**到插件数据目录（`tg.session`）再连接，避免和爬虫 GUI 抢同一个 SQLite 文件锁。
- Telethon 客户端固定在一个**后台线程的独立事件循环**里常驻运行：连接和群实体只建一次，每次巡检只发一个 `get_messages`。
- 实测（同一台机、同一代理）：首次连接约 1.2s，之后取增量约 0.25s，无新增约 0.11s，卡片渲染约 30ms。
- 游标 `last_id` 存在 `state.json`，用 `min_id + reverse=True` 往后取，单次上限 `max_fetch` 条，超出不跳消息；游标推进用临时文件原子替换。
- 只统计条数、昵称、时间，**不读取或回传任何消息正文**（避免腾讯审核拦截）。
- 卡片图用本地 Pillow + 微软雅黑渲染（`C:\Windows\Fonts\msyh*.ttc`），字体对象进程内缓存，`cards/` 目录只保留最近 10 张。
- 必须 `python-socks`；装成 `pysocks` 会静默直连导致超时。
