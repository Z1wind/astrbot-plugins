# astrbot_plugin_menu · 乐乐功能菜单

AstrBot 内置的 `/help` 只会列出**系统保留命令**（`/reset`、`/sid`、`/stats` 等），
看不到插件提供的聊天、情感、基金、群指令。

这个插件补一个面向使用者的 `/菜单`：

```text
乐乐 · 能做什么

聊天 / 情感：私聊直接说话就行；烦心事、感情问题直接讲，我会先接住再判断。
基金：直接问，或 @我 说「涨跌榜」看群里的基金数据。

群里的开关（@我 后单独发）：
  闭嘴 / 说话 / 爬楼

小工具（@我 后发）：
  涨跌榜        群基金涨跌 / 持仓
  验车 <磁力>   种子、磁力信息分析
  弗一把        猜 CS 选手
  op无人        OOPZ 在线人数
  反查 / 识人   截图反查（发图后说）

管理员：
  /dsh <任务>   让本机 DeepSeek Harness 干活（仅私聊）
  /dsh status   看 DSH 桥状态
  /help         AstrBot 内置命令
  /reset /new /stop /sid /stats   会话与调试

已下线：/crush 暗恋排练（2026-10-27 卸载）。
说明：/help 只列系统命令；这个菜单才是乐乐的功能入口。
```

## 命令

| 命令 | 说明 |
|---|---|
| `/菜单` | 显示菜单；非管理员不显示管理员段 |
| `/helpall`、`/功能`、`/菜单帮助` | 别名 |

群里同样可用；群友看到的是非管理员版菜单。

## 设计取舍

- **纯文本、无 LLM**：菜单不该消耗 token，也不该被情感路线改写。
- **管理员段按 `event.is_admin()` 隐藏**：不把 `/dsh` 这种高权限入口广告给普通群友。
- **静态内容**：命令变了要手动改 `main.py` 的 `build_menu()`；好处是不会在运行时读插件注册表、不会因某个插件加载失败而整页崩。
- 不覆盖内置 `/help`，避免两个 handler 同时回。

## 部署

```powershell
.\scripts\deploy.ps1 -Plugins -Only astrbot_plugin_menu -Apply -Restart
```
